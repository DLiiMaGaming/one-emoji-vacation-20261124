One Emoji, One Dream Vacation — a [make.fun](https://make.fun/c/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) entry.

`main.py` writes exactly one emoji to `/output/entry.txt`:

> 🏝 — U+1F3DD DESERT ISLAND

One glyph, one dream: a desert island — palm, sand, sea and sky. A postcard
at a glance, a specific faraway place rather than any generic holiday, and
readable instantly on any screen.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Output: a single character (1 code point, 4 bytes UTF-8), no trailing newline.
